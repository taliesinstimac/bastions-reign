# bastions-reign
taking back what replit so brutally stole from me
There once was a time where we had coding third spaces.
Code playgrounds, even.
It's where I learned to code.
Determined to learn C++ for fun as a child, I worked tirelessly on a text-based RPG in replit.
It was called Bastion's Reign.
It was branching. It was glorious.
At/around 2023, this beautiful infrastructure came crumbling down.
All my little projects from middle school were wiped.
Now I'm a grown man and I know, roughly, how to use a git repo and VSCode.
I do not, however, remember any of the C++ skills I gained. I know only JS and Python.
So, here is the new-and-improved Python-based "Bastion's Reign."
Enjoy!
